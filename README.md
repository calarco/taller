# Taller

Sistema de gestión para talleres mecánicos: clientes, vehículos, reparaciones, turnos y presupuestos.
Los presupuestos se imprimen a PDF desde el navegador o se envían por correo.

SvelteKit 2 con Svelte 5 (runes), Mongoose y `@sveltejs/adapter-node`. La interfaz está en español.

## Comandos

```bash
npm run dev            # servidor de desarrollo
npm run build          # build de producción
npm run lint           # prettier --check + eslint
npm run format         # prettier --write
npm run demo:fixture   # regenera src/lib/server/demo-fixture.json
```
